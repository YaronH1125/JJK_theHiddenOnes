# 需求说明

版本：v0.3；日期：2026-09-15。决策状态说明见 [开发约束与决策记录](03_开发约束与决策记录.md)。

## 1. 项目目标

制作一个用于应届生游戏客户端开发求职的第三人称 1v1 擂台格斗训练 Demo，展示 C++、UE Gameplay Framework、GAS、动作交互、AI 与工程验证能力。

**项目 IP 已确认为《咒术回战》。** 角色选择、术式设定与后续内容方向以该作品为依据，首个实机角色为石流龙。IP 确认不扩大首版单角色训练 Demo 的功能范围。

玩法方向参考《异人之下》的第三人称擂台对抗、招式交互与取消变招；首个实机角色已确认使用《咒术回战》的石流龙，突出重拳与高输出咒力炮击。训练功能参考对战游戏训练场：有一个对手，可关闭主动行为作为木桩，也可开启 AI 模拟对战。

角色资料、官方形象和技能改编边界见 [石流龙角色方案](06_石流龙角色方案.md)；实机场景参考与本项目白盒布局见 [擂台与视觉参考](07_擂台与视觉参考.md)。角色身份已确认，技能名称、数值和布局仍为可调整方案。

项目不以完整复刻参考游戏为目标。下文招式数量、克制关系和资源机制属于本项目当前默认方案，仍可通过原型调整。

## 2. 成功标准

- 可独立运行，进入擂台后可以移动、转动镜头、攻击和练习。
- 单角色具有完整的进攻、防御、受击、恢复和死亡流程。
- 木桩与 AI 使用相同战斗规则；AI 不通过直接扣血或直接播放攻击动画绕过规则。
- 能解释输入到能力执行、命中、效果、反馈的完整链路。
- 取消、死亡、目标失效与重置不产生卡死、残留碰撞或重复伤害。
- 新增同类招式主要修改配置；新机制有明确扩展点。
- 有可运行包、演示视频和简短技术说明；性能结论带测试环境与测量依据。

## 3. 使用流程

1. 进入一个平坦擂台，生成玩家和一个对手。
2. 默认进入木桩练习，可通过训练面板切换固定防御或 AI 对战。
3. 玩家可自由移动和转动镜头，进行普攻、技能与攻防练习。
4. 面板可设置生命恢复、无限资源、无冷却及调试显示。
5. 随时快速重置位置与战斗状态。
6. AI 对战中一方死亡后停止对抗，显示结果并允许重开。

## 5. 核心攻防规则

核心循环：移动观察 → 普攻或技能试探 → 防御或闪避 → 取消变招 → 命中连段 → 对手恢复 → 重新交战。

2026-09-17 用户确认补充：移动中按 Shift 冲刺闪避，按住持续跑；静止按下后撤，成功避开攻击有动作与反馈。提前提供开发用常驻双方生命及资源 UI，正式美术后续替换。持续跑不延长无敌；具体成本和恢复仍按 [08](08_石流龙战斗系统设计.md)。

| 动作 | 默认规则 |
| --- | --- |
| 普攻 | 可衔接三段；末段击退。对符合距离、方向、地面和可抓取条件的防御目标，可转投技 |
| 平招技能 | 指定阶段抗普通攻击打断，但仍可受伤；可被正面防御 |
| 防御 | 挡住可防御攻击，产生短暂防御硬直；不能挡投技，不自动触发反击 |
| 闪避 | 指定窗口内免疫规定类型的伤害，存在恢复时间 |
| 取消 | 仅在允许窗口内执行；消耗行动资源；不能无条件消除所有后摇 |
| 普通受击 | 按招式规则打断当前动作，产生受击硬直 |
| 霸体 | 对规定等级的打断免疫；不等同于无敌 |
| 倒地 | 第一版有倒地保护，起身结束后恢复行动 |
| 死亡 | 停止当前战斗行为并禁止新动作，根据模式重置或显示结果 |

不引入精确防御、振刀窗口、成功振刀奖励或防御自动反击。后续若重新增加这些机制，需要重新讨论范围。

首版不把持续扣防御条作为核心。防御的收益通过投技威胁、方向、硬直和移动限制平衡。是否保留少量防御削血为待调参数，不能默认既存在防御值又存在一套重复的防御资源。

投技成功后协调双方动作，限制双方控制并保证异常退出可以恢复。仅做一个地面投技，不建设通用抓取、空投、拆投和多人抓取系统。若首阶段缺乏合适动画，允许用明确标注的占位动作验证规则。

## 6. 取消与资源

当前推荐使用生命、行动资源、咒力、领域能量四类数值，详细规则与起测参数见 [08](08_石流龙战斗系统设计.md)：

- 生命决定存活。
- 行动资源约束普通闪避和闪避取消；同一 Shift 请求只扣一次总成本，成本与恢复规则待调。
- 咒力用于远程炮击，近战拳脚不消耗咒力。
- 领域能量用于绝技，非领域期有效战斗积累；领域期间不自充。

普通炮通过咒力与恢复时间约束，定点超级炮另有冷却；形态切换不刷新冷却或免费取消。新增独立咒力是对用户远近战资源要求的默认实现，取代早期三资源建议。领域追踪炮实际接触才伤害，不能用瞬时扣血伪装曲线；不绕过死亡、倒地和重置保护，防御与双领域压制按 08 的项目规则处理。

2026-09-16 用户确认：Shift 闪避并在合法窗口取消动作；F 按住防御；远程右键按住瞄准，空格暂预留。远程炮击伤害封顶后可持续持炮，松开才发射，咒力成本随伤害提高并封顶。满蓄与资源不足均不强制发炮；窗口、镜头、成本及冷却建议以 [08](08_石流龙战斗系统设计.md) v0.2 为准。

取消只在招式配置允许时发生。普通受击、投技演出和死亡不能通过普通主动取消脱离。取消停止后续动作，不撤回已造成的伤害；已发射投射物由该招式配置决定保留或销毁。

## 7. 镜头、目标和方向

必须分别管理摄像机朝向、角色朝向与攻击方向。

- 鼠标或右摇杆始终可转动普通战斗镜头。
- 锁定目标只表示持续选择该目标，不强制每帧把摄像机转向对手。
- 提供手动回正；自动辅助应在玩家转动镜头时暂停或减弱。
- 普通移动以摄像机水平朝向计算；战斗姿态可面向目标侧移。
- 攻击只在指定起手阶段内有限转向，配置最大转角、最大距离和停止追踪时机。
- 目标死亡、失效、离开范围时清理目标；允许技能按配置空放。
- 特殊绝技镜头只在后期按需接入，结束或中断后恢复玩家镜头。

## 8. 训练模式

| 模式 | 行为 |
| --- | --- |
| 静止木桩 | 不主动发出动作请求，但正常受击、击退、倒地、恢复 |
| 固定防御 | 可行动时持续请求防御；受击打断后按规则恢复 |
| AI 对战 | 根据距离、资源和可观察动作做移动与攻防决策 |

禁止通过关闭角色 Tick、GAS、碰撞或动画的方式实现木桩。

| 设置 | 语义 |
| --- | --- |
| 自动恢复生命 | 连击结束或指定延迟后恢复 |
| 无限生命 | 保留实际伤害统计和受击结果，阻止死亡；处理位置要早于死亡事件 |
| 无限资源 | 消耗检查和实际扣除同时使用训练规则，不能只是不扣数值 |
| 无冷却 | 清理已有对应技能冷却，并跳过后续冷却应用 |
| 快速重置 | 回到双方初始位置、属性和指定行为模式 |
| 调试显示 | 输入记录、当前能力、标签、动作窗口、命中轨迹 |

连击统计以受击方是否恢复可行动为基础，并结合倒地保护规则结束连击；不只用两次伤害间隔猜测连击。

## 9. 不在当前范围内

- 联网 PvP、匹配、服务器部署、延迟补偿、回滚与完整客户端预测。
- 振刀、精确防御、连续拆招。
- 多角色轮换、援助角色、复杂空战、墙弹、无限连系统。
- 开放世界、关卡探索、装备养成、背包、任务和剧情系统。
- 大型通用框架、全局消息总线、自研资源加载框架。
