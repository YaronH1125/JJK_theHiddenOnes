## 当前最重要的约束

- 使用 UE 5.8；本机静态检查确认已安装 5.8.2。
- 使用 GAS 作为战斗能力、属性、效果与状态管理基础。
- 第三人称自由镜头；锁定目标不等于锁死镜头。
- 场景是擂台，玩家面对一个对手，对手可切换木桩和 AI。
- 当前不做联网 PvP，也不做振刀、精确防御或连续拆招机制。
- 控制范围，避免直接搬入大型项目的完整框架。
- 优先交付单角色完整战斗闭环，再考虑角色扩展。
- 首个实机角色已确认使用《咒术回战》的石流龙；双方镜像使用仍为当前默认方案。
- 项目 IP 已确认使用《咒术回战》，不再保留 Fate 等其他 IP 候选。
- 保留旧项目，选择性复用代码思路、算法、参数和资源。

## 如何理解“已确定”和“建议”

本套文档区分三种状态：

1. **已确认约束**：来自用户明确要求，例如 UE 5.8、GAS、自由镜头、无联网 PvP、无振刀。
2. **当前默认方案**：为了开始实施而提出的可调整设计，例如单角色镜像对战、三段普攻、普攻对防御转投技。
3. **待定事项**：美术资产适配、技能具体表现、按键、帧窗口、资源消耗等，不能写成已实现或最终定案。石流龙的角色身份已于 2026-09-15 确认。

当前默认方案可以作为原型开发起点；发生实质修改时，同步更新需求和相关验收条目。
