## HUD 与菜单

- [13 对战 HUD 设计稿](13_对战HUD设计稿.md)：四资源、蓄力、领域状态的信息与视觉设计。

- [21 菜单 UI 设计稿](21_菜单UI设计稿.md)：主菜单、模式选择、暂停、设置、操作说明与 UE 接入；[菜单原型](assets/menu-ui-v1.0.html) 仅用于设计预览。

`assets/` 下的 HTML 使用 Microsoft Edge 打开。网页交互、PIE、独立包主菜单与完整战斗的验证范围分别记录，不把设计原型操作当成实机战斗。

主要 HUD 原型为 `hud-prototype-v9.0.html`，配套规范为 `od-hud-states-v9.0.html`。早期 `hud-states.html` 与角色 / 游戏参考图保留用于设计追溯。
