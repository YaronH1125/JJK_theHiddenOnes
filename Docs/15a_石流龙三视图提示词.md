## 1. 使用说明（先读这七条）

1. **一图一视角，共生成三条。** 正视图、左侧视图、背视图**各生成一张**，右侧视图由左侧图水平镜像得到（见 §3.4）。不要把多个视角塞进一张图——那样每个视图都很小、细节和比例都不可靠。
2. **正视图和背视图必须左右对称。** 不对称的头发会让建模无法镜像，只能左右各修一遍，工作量翻倍。所以这两张图的提示词里都单独写了"以中线为轴严格镜像对称、头发无偏分"。生成后自己沿中线折一下看，不对称就重生成。
3. **必须要求"无手部遮挡、手臂分开"。** 手臂贴着身体或手插兜，会导致图生 3D 把手臂和躯干黏成一块，后期修起来比重新生成更费时间。
4. **必须要求"平光、无阴影、无背景元素"。** 强对比光影会被部分工具当作纹理烘进模型；背景道具会被当成角色的一部分生成出来。
5. **三张图的角色高度必须一致。** 拼进四个槽位之前先比对，侧面比正面高就重生成侧面——图生 3D 会按像素比例反推身材。
6. **纯文字描述不足以锁住发型和脸。** 把参考图一起传给模型做图生图，并在提示词开头加一句"发型、脸型和服装请严格参照我上传的参考图"，效果远好于继续加形容词。
7. **上传尺寸**：Tripo 多视图槽位要求 JPG/PNG/WEBP、**单张 ≤ 20MB**。生成的高清原图若超限，转成 JPG（质量 90）即可，但不要把分辨率压到 1K 以下——头部细节会糊。

> 版权口径沿用工程约定（[14 §10.1](14_HUD开发指引.md)）：本提示词产出的图是**角色设计参考**，与官方无关，不得进正式作品集或发布版本的素材清单。作为图生图输入的实物手办照（含 `BANPRESTO`、`Hpoi` 水印）属于第三方素材，**只用于个人参考，不能进仓库、不能进交付包**。建议生成后在图角自行标注"非官方设定 / fan concept"。

## 3. 三条提示词（右侧由左侧镜像得到）

> **对应 Tripo 多视图界面的四个槽位：`前` / `左侧` / `右侧` / `后`。**
> 只要生成 **正视图 + 左侧视图 + 背视图 三条**，然后把**左侧视图水平镜像**得到右侧视图。
> 分别生成左右两张会让毛领厚度、衣摆长度、发型侧面厚度对不上，多视图图生 3D 反而更容易糊。这是本流程的硬要求，不是省事。

### 3.4 怎么把左侧图变成右侧图（30 秒）

任选一种，**必须水平翻转（左右镜像），不要旋转**：

- **Windows 照片**：打开左侧图 → 编辑 → 翻转 → 水平翻转 → 另存为 `right.png`
- **PowerShell（无脑批处理）**：

  ```powershell
  Add-Type -AssemblyName System.Drawing
  $src = [System.Drawing.Image]::FromFile("F:\...\left.png")
  $dst = New-Object System.Drawing.Bitmap($src.Width, $src.Height)
  $g = [System.Drawing.Graphics]::FromImage($dst)
  $g.DrawImage($src, (New-Object System.Drawing.Rectangle(0, 0, $src.Width, $src.Height)),
               0, 0, $src.Width, $src.Height, [System.Drawing.GraphicsUnit]::Pixel)
  $dst.RotateFlip([System.Drawing.RotateFlipType]::RotateNoneFlipX)
  $g.Dispose(); $dst.Save("F:\...\right.png", [System.Drawing.Imaging.ImageFormat]::Png)
  $dst.Dispose(); $src.Dispose()
  ```

## 6. 与后续环节的衔接

四张图出齐之后，不要直接丢进图生 3D，先做两件事：

1. **四张并排比对一致性**：身高是否一致、毛领厚度是否一致、外套长度是否一致、皮带扣是否一致。不一致的那张单独重生成——**图生 3D 只会照单张图编细节，四张不一致时没人能判断哪个是对的**。
2. **分件再生成**：按 [15 §11.2](15_石流龙AI建模与UE接入流程.md) 的拆件策略，用同一套共用特征块给【身体 / 头发 / 敞开的外套 / 毛领】各单独生成一张**单体**图（提示词末尾加"只画这一个部件，纯浅灰平背景，画面中央放大显示"），比让 AI 一次生成整个角色再切分干净得多。

**图生 3D 时用哪张**：先用**正视图**单图生成一版看效果；背面细节不对时，再用 Tripo/混元的多视图模式把**正 + 左 + 背**三张一起喂进去锁背面。四分之三那张不参与生成，只用来人工判断体积对不对。

**要额外备份的输入**：工程里已有的旧高模（`F:/GameStudy/JJKDemo/sll/T.fbx`，190.479 cm / 65 骨）可以导出正侧背三张正交渲染图，作为三视图的**比例校准参照**——把 AI 生成图和旧模渲染图并排比对，能提前发现"AI 把腿画长了/头画大了"这类会直接毁掉重定向的问题。
