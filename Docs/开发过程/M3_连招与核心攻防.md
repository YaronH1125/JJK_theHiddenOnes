# M3：连招与核心攻防

版本：v0.1；建立日期：2026-09-15；实施与自测状态：待核验。

[开发过程导航](README.md) · 上一阶段：[M2](M2_单次攻击闭环.md) · 下一阶段：[M4](M4_训练系统.md)

## 1. 目标与进入条件

基于 M2 的可靠单次攻击，完成三段连击、缓存、持续防御、方向闪避、主动取消、条件投技与完整受击生命周期。M2 的重复命中、异常清理与重置问题必须先解决。

本阶段以占位动作也能验证完整攻防。无振刀、精确防御、拆投、空投、墙弹和联网逻辑；不新增独立防御条。

## 2. 实施前需要记录的规则

最新角色输入按 [08](../08_石流龙战斗系统设计.md)：推荐左键拳/长按重拳、Q 腿/长按重踢、E 切形态。先用占位动作实现轻重识别和近战规则，远程形态可暂不发炮。追加执行 SLL-T01—T04；E 不能绕过动作限制，菜单/失焦后的松键不提交攻击。拳脚不消耗咒力。

这些参数尚未定案，实施时放到配置并记录当前值；不要把调试值称为原作或参考游戏官方数据。

| 配置组 | 必须明确的字段/语义 |
| --- | --- |
| 连招 | 每段起手/有效/恢复时间、衔接窗口、命中与空挥是否允许衔接 |
| 输入缓存 | 单槽寿命、动作覆盖优先级、方向采样时点；防御按住状态独立保存 |
| 防御 | 可防御类型、正面角度、防御硬直、削血是否启用及默认值 |
| 闪避 | 位移、无敌类型/窗口、恢复、是否消耗行动资源 |
| 取消 | 各动作允许窗口、允许目标动作、行动资源消耗与恢复 |
| 投技 | 可转投的普攻段、距离/角度、地面/可抓取条件、配对位置与释放时机 |
| 受击 | 打断等级、霸体抵抗等级、击退、倒地保护、起身结束与死亡限制 |

## 3. 开发步骤与局部检查

### M3.1 将单段扩为三段

一个 MeleeCombo GA 持有当前段数，每段独立命中记录和窗口。衔接时更新段号及动画段落，不重新误授予能力。第三段产生配置的击退，结束后回到可行动。

局部检查：单击只走第一段；按窗口输入可连续三段；每段伤害次数与配置一致。

### M3.2 增加单槽缓存

请求保存动作、方向和时间，窗口打开时重新检查状态、目标与资源，成功消费后立即清除。过期、死亡、模式切换和重置时丢弃；缓存不能授予本来不允许的取消权限。

持续防御单独记录按下/松开，受击期间松开也必须收到；菜单切换或失去游戏输入时释放持续意图，避免恢复后粘住。

局部检查：过早输入过期后不补招，有效缓存只执行一次。

### M3.3 接持续防御与方向闪避

共享结算按攻击来向、角色防御朝向和类型判断，不按相机朝向决定正面。防御只产生配置的防御结果与硬直，无时机奖励。防御/无敌结果按本段规则消费命中，不能下一采样绕过第一次防住的结果。

闪避单独管理位移、无敌和恢复窗口，结束/中断释放自身状态。霸体与无敌分开：霸体仍可扣血，只抵抗规定等级打断。

局部检查：正面防住、侧后方按规则命中；闪避只在规定窗口免伤；结束后可恢复正常受击。

### M3.4 接 Shift 闪避取消与行动资源

只有当前动作允许、处于窗口且资源足够时提交 Shift 闪避取消；Dodge 先通过全部检查，才停止旧 GA 检测、清理会话并进入闪避。失败保留原动作。普通闪避起测成本 1，取消闪避总计 2，不叠加扣成 3；恢复或合法衔接后才能执行 E/新招。没有独立原地取消键。

F 为按住防御，不能直接取消攻击；右键不再防御。Shift 无方向默认后撤，按住不连续闪避，闪避恢复不可自取消。远程右肩瞄准镜头在 M6 实现。

配置合法变招集合，不允许所有动作任意互相取消。普通受击、投技演出和死亡不能用普通取消脱离；已经造成的伤害保留。

局部检查：窗口外、资源不足均拒绝，合法取消后可继续行动且没有旧招延迟命中。

### M3.5 做单个条件投技

普攻结算遇到防御目标时，检查距离、方向、地面、可抓取状态与配对占用。条件满足才转为投技结果，同一次接触不再追加普通命中伤害。

先验证配对位置能在边界内安全落地，再限制双方控制和播放配对动作；不合法时退回原防御结算。任何一方死亡、销毁、重置或动画失败都释放双方配对、限制和引用。

局部检查：合法条件可投，距离过远/空中/已有配对不可投；边缘不会把目标移出擂台。

### M3.6 串联受击、击退、倒地、起身和死亡

将状态与动作中断规则明确交给 GA/GE 管理，AnimInstance 只读。倒地保护期间按配置拒绝再次进入普通连段；起身结束才恢复行动。死亡停止所有主动请求与现有攻击，等待重置。

普通移动、Root Motion、击退和投技配对同一时刻只有明确的控制来源；退出恢复正确的移动模式和旋转设置。

局部检查：受击→倒地→起身后可以移动攻击；死亡后不能闪避/取消逃离状态；重置双方都可继续。

## 4. 本阶段自测

可通过开发对手动作入口制造防御和攻击，所有主动动作仍走共享请求。

| ID | 前置与操作 | 预期结果/观察点 |
| --- | --- | --- |
| M3-T01 | 单击、窗口内连按、第三段结束再按 | 段数与衔接符合配置，每段只结算规定次数 |
| M3-T02 | 有效缓存、过期缓存、多个动作抢同一缓存槽 | 有效输入只执行一次，过期丢弃，覆盖优先级有记录 |
| M3-T03 | 缓存后令资源不足、目标失效或角色死亡 | 窗口打开再次验证，不越过规则执行 |
| M3-T04 | 对手防御时分别从正面与背面攻击 | 按来向和类型结算，无精确时机反击 |
| M3-T05 | 防御受击后在硬直中松开，或打开菜单 | 恢复后不错误继续防御；持续输入被正确释放 |
| M3-T06 | 在闪避前、中、后分别命中 | 仅指定无敌窗口/类型免伤，恢复期间按规则受击 |
| M3-T07 | 窗口内/外、资源足/不足四种取消组合 | 只有同时合法时成功；消耗一次，无旧检测残留 |
| M3-T08 | 普通受击、投技演出、死亡时请求取消 | 请求拒绝，不能无条件脱离 |
| M3-T09 | 防御目标满足/不满足抓取条件 | 合法接触转投，不双重扣血；非法保留防御结果 |
| M3-T10 | 投技中双方分别死亡、销毁、重置或停动画 | 双方控制/配对均恢复，无单方永久锁定 |
| M3-T11 | 边缘投技、击退、闪避及移动输入竞争 | 不越界；移动控制无抖动争抢；取消后设置恢复 |
| M3-T12 | 霸体受击；普通受击→倒地→起身→再攻击 | 伤害与打断分离；倒地保护和恢复时点正确 |
| M3-T13 | 30/60/120 FPS 重复连段与窄窗口取消 | 记录实际时序，无明显漏窗口或无限连；保留差异 |
| M3-T14 | 攻击被防住/免疫后，窗口内继续接触目标 | 不因下一次采样重新绕过防御/免疫结算 |
| M3-T15 | Shift 在窗口内/外，行动资源足/不足 | 合法才取消并扣一次总成本，失败原动作继续 |
| M3-T16 | Shift 与攻击松开同帧，按住 Shift，闪避恢复中 E | 成功取消不补攻击，失败不吞合法松开；无自动连闪或免费跳过恢复 |
| M3-T17 | F 按住/松开、攻击中 F、菜单/失焦 | 不免费取消攻击，恢复后无粘住防御 |

## 5. 必须演示的闭环

三段普攻 → 对手防御 → 合法条件转投 → 双方释放 → 对手攻击 → 玩家闪避/防御 → 合法取消变招 → 击退倒地起身 → 一方死亡 → 重置再次出招。无 AI 时分段用调试入口触发，并标明操作方式。

## 6. 完成标准与交接

- [ ] 上述动作与状态有明确持有者，完整闭环可运行。
- [ ] 缓存、取消、防御、投技和移动控制异常路径通过。
- [ ] 当前窗口、资源、方向与抓取规则已存配置并写入记录。
- [ ] 向 M4 提供“恢复可行动/连击结束”等真实战斗事件，而非仅动画计时猜测。
- [ ] 向 M4 交接持续输入释放、模式停止和集中重置入口。

永久硬直、无限取消、投技单方卡死或死亡后能出招都阻塞 M4。配对动画可以占位，但规则与异常清理必须真实完成。
