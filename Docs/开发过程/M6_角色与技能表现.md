## 1. 目标与进入条件

把 [08_石流龙战斗系统设计](../08_石流龙战斗系统设计.md) 落地：近战拳/腿与长按重击、远程移动蓄力炮/定点超级炮、技能二切换形态、领域绝技与自动满威力曲线追踪炮。

本版替代旧版“重拳技能、基础炮技能、强化炮绝技”配置。M5 的共享 AI、M4 的训练与重置应先稳定；M3 已验证轻重输入和近战占位。既有 M0/M1 记录不因本次设计修改而改成未完成，但新增字段仍须验证。

## 2. 预期交付

正式石流龙角色定义和动画、形态输入解析、MobileChargedBlast、StationaryChargedBlast、SwitchStance、DomainExpansion、咒力/领域能量配置、领域会话与表现、对应 AI 行为。名字是建议，按真实落地记录。

## 3. 开发步骤与局部检查

### M6.1 正式角色与近战回归

检查旧素材来源、Skeleton、比例、朝向、材质及重定向；验证三段拳、重拳、腿/重踢、防御、闪避、投技、受击、倒地/起身/死亡。头部炮口、拳脚检测 Socket 和 Capsule 均重新核验。

双方共享资源配置但动态材质、ASC 与输入状态独立。先跑 M3 完整闭环，不在换骨骼时同时重写伤害规则。

局部检查：拳脚不耗咒力，配对投技不越界，换模型未破坏命中去重或移动。

### M6.2 形态与蓄力输入

左键与技能一按当前形态解析；技能二负责互斥形态转换。按下记录 InputSessionId 和形态，松开只向对应活动会话提交；轻重阈值、缓存覆盖与蓄力上限读配置。

蓄力中禁止直接切形态，攻击后摇不能用 E 免费取消。菜单、失焦、死亡、重置清理会话并要求重新按下，不触发旧松键炮击。领域状态与形态分开，不用一个枚举覆盖所有组合。

局部检查：旧近战按下不会在远程松开出炮；切形态不刷新冷却或遗留动画状态。

### M6.3 移动蓄力炮与普通检测

接头部 Muzzle_Head，先实现镜头到瞄准点、炮口到最近阻挡的检测，再接光束。按实际游戏时间推进蓄力、成本与伤害，移动减速；封顶后持续保持，松开才进入锁向前摇并发射一次。资源不足仅限制强度，不强制发炮；持炮暂停被动回咒。

按 08 第 4.4 节实现远程右键按住右肩瞄准，只参考旧项目镜头相关源码。镜头平滑拉近/偏移、角色随视角转向、准星与炮口受阻反馈分别验证。蓄力与瞄准独立，不重复相乘减速；松右键不发炮。Shift 成功清攻击会话并退出瞄准，F 不直接取消攻击。

普通领域外规则不穿墙，炮口嵌墙安全拒绝。粒子持续不重复伤害，正式命中统一经 GE/受击结算。资源不足不能发出超出已支付等级的炮击。

局部检查：不同时间松开对应明确伤害和成本；无目标可空放；边界遮挡有效。

### M6.4 定点超级蓄力炮

技能一在远程形态进入站定蓄力，设最低发射门槛、伤害封顶时间、转向截止和恢复，满蓄保持不限时。基础咒力在合法激活时提交，增量随伤害增长支付；冷却在实际发射或已付费中断时启动一次，持炮不能提前等完冷却。

未达门槛松开则收招，已扣部分不退；发射前中断无伤害，已命中不回滚。按 08 的可取消窗口处理，不把切形态当取消。对波只作姿态/蓄势参考，不实现光束比拼。

局部检查：普通炮与超级炮用途/风险不同；超级炮空招承担后摇，满蓄不自动发射，合法松开只发一次。

### M6.5 咒力与领域能量循环

新增独立咒力，近战有效命中少量恢复、停止炮击后延迟恢复，具体初值和公式见 08。领域能量由非领域期有效战斗积累，领域期间禁止自充。

重置恢复初始形态与四类数值；无限资源同时覆盖检查和实际扣除，无冷却不删除蓄力门槛、后摇或切形态间隔。移除/隔离 M4 测试能力，用正式动作复验。

局部检查：不开无限资源也能近战积累、远程消耗、获取领域能量并开启领域。

### M6.6 领域会话与必中

先完成结印、能量提交、目标捕获、参与者登记和时限，再做美术。失败不退已提交能量，成功沿用当前擂台，不传送或插入会夹住角色的新碰撞边界。

按 08 v0.3 接自动调度，不等待 Q 蓄力或松键；每发复用超级炮最大伤害/成本配置。先生成球体占位与曲线飞行，再接扫掠命中；实际接触前不得扣血。连续修正路径并保持切线，不能每帧直线锁头；普通闪避免疫不抵消实际接触，倒地/死亡/重置保护仍生效。

双领域并存时暂停自动炮并清在途球，独立计时；一方结束后另一方下个原定时点恢复，不补齐漏发炮次。死亡、对象失效、重置、EndPlay 清自己的会话和临时状态，最后一个领域结束才清共享穹顶。

局部检查：领域自动生成满威力炮，生成扣咒力，球接触才伤害一次，不同时提交射线/直接伤害；结束即停调度并清球。远程手动炮在领域期禁用，结束需新按下恢复。

### M6.7 AI、表现与独立包

AI 合法切形态，依距离/可观察动作决定移动炮或超级炮；领域中对手选择压制术者阻止新炮生成或防御，不以无限闪避假装反制成功。双方都能合法展开领域。

以原创概念图指导夜空/烟火，不照搬成高负载满屏粒子。环境烟火无伤害，每次发射才有命中表现；HUD 显示形态、咒力、领域时间和压制状态。自由镜头正常恢复。

更新独立运行包，验证新增资源和领域表现完整 Cook。局部检查：整套规则在编辑器外可运行。

## 5. 必须演示的闭环

正式石流龙近战拳腿 → 命中回咒力 → 合法切远程 → 移动炮 → 大破绽下超级炮 → 领域结印/捕获 → 自动生成曲线球 → 接触结算 → 双领域压制清球 → 领域到期 → 重置再战。

另演示菜单/失焦旧松键、领域失败和倒地保护三个异常场景；录像标明原创领域规则，不称为官方还原。

新增闭环：远程右键瞄准 → 移动蓄力并满蓄保持 → 松右键继续持炮 → 松左键发射 → Q 站定满蓄 → Shift 取消 → 冷却与已耗咒力保留 → 恢复后 F 防御/切近战 → 重置。将镜头、耗咒与冷却的证据交 M7。
