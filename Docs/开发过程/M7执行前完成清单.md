### A02 炮击方向、遮挡和共享攻防

- [x] 镜头到瞄准点、炮口到最近阻挡全路径检测；中间墙体截断，炮口嵌墙拒绝，特效终点与命中一致。（Visibility 世界阻挡 + Pawn 对象扫掠取近者；嵌墙 30cm 拒绝；墙在 30cm 外仍拦截——M7_A A02_wall_blocks_blast）
- [x] 锁定身份与瞄准方向解耦；释放时固定发射方向，锁向前摇不继续瞬时追随目标。（`LockedAimPoint` 于松开捕获）

依据：`ChargedBlastAbility.cpp::FireOnce` 当前锁定目标直接覆盖镜头目标点，主要扫掠只查 Pawn，世界阻挡只检查炮口前 30 cm；在该路径未见完整镜头/炮口两段遮挡和统一防御分支。`DomainOrb.cpp::CheckContact` 直接施加伤害 GE，未见方向防御减伤。需补对照近战统一结算的测试，不能以“已扣血”替代全部攻防验收。

验收：墙在炮口 30 cm 之外仍阻挡；前后防御；普通炮面对闪避免疫；领域球尊重倒地/死亡保护且按设计减伤；只结算一次。对应 M6-T06/T08、SLL-T07/T10。

### A03 蓄力强度与实际成本一致

- [x] 超级炮按 `clamp((t-1.2)/1.2,0,1)` 增长，最低门槛前仅基础成本。（`ComputeChargeQ` 虚函数；门槛前零增量，实测 45 精确）
- [x] 资源不足时最后支付的部分计入累计成本和强度，不吞掉余额；保持不自动发射。（耗尽分支 `PaidCost+=Curse`；松开时 `UpdateChargeProgress` 补齐末段；实测咒力 50→强度 167.5、归零不负）
- [x] 无限资源检查与扣费统一；切回正常资源清持炮会话，领域开启也遵守训练设置。（`ModifyEnergy` 补 HasInfiniteResources 豁免；切形态中止持炮 `CancelFromOutside`）

依据：`HandleChargeTick` 两种炮共用 `Elapsed/CapTime`，超级炮没有扣除最低门槛；报告中“门槛前收招”实际成本约 **49.167**，与文档“只扣 45”不符。资源不足分支扣剩余咒力但未把余额加入 `PaidCost`。`ModifyEnergy` 未见无限资源豁免，而 `ModifyCursedEnergy` 存在该处理，需验证领域与训练口径。

验收：最低门槛前/恰好门槛/满蓄；普通炮 16 咒力对应最高 60 伤害；正常与无限资源来回切换；不负资源、不双扣、不免费满蓄。对应 M6-T05/T12/T17。

### A04 领域不能给自己充下一次能量

- [x] 领域期间禁止领域能量获取；普通命中能量按有效结算伤害与攻击实例去重。（`IsDomainActive` 拒绝 + `LastGainInstanceId`；近战按实例×1000+段合成键）
