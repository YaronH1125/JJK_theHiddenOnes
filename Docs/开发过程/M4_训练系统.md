# M4：训练系统

版本：v0.2；建立日期：2026-09-15；验收日期：2026-09-16；状态：M4 训练闭环已完成，可进入 M5。

[开发过程导航](README.md) · 上一阶段：[M3](M3_连招与核心攻防.md) · 下一阶段：[M5](M5_AI对战.md)

## 1. 目标与进入条件

让玩家通过面板稳定设置训练规则、观察反馈并快速重置。M3 的攻防与恢复事件已可运行；基础重置来自 M2，不能另建一套绕过清理的新流程。

本阶段完成静止木桩、固定防御和 AI 模式的接口。真实 AI 在 M5 实现，M4 的 AI 选项禁用并标明未接入，不能选择后悄悄退回木桩。

## 2. 交付与规则真值

当前资源语义更新为 [08](../08_石流龙战斗系统设计.md) 的生命、行动资源、咒力和领域能量。无限资源覆盖后三项的检查和扣除；重置还要结束领域、清蓄力输入并恢复默认近战。领域正式功能在 M6 集成，当前不可用时明确标记。

TrainingGameMode 保存训练设置与重置入口；UMG 发送设置意图并订阅结果。生命和冷却显示读取 ASC，不由 UI 维护第二份战斗数值。

| 设置 | 必须贯穿的路径 |
| --- | --- |
| 自动恢复生命 | 真实连击结束/配置延迟后恢复；再次受击取消旧恢复计划 |
| 无限生命 | 保留结算伤害与受击，在死亡判断前限制实际生命减少 |
| 无限资源 | 消耗检查允许执行、实际扣除跳过；其他状态限制仍生效 |
| 无冷却 | 开启时移除已有对应技能冷却，后续不应用；不清除其他 GE |
| 快速重置 | 统一停止、清理、复位、恢复属性和统计，再恢复模式 |

默认自动恢复和无限生命独立；死亡后自动恢复不隐式复活，使用重置重开。开关关闭只恢复正常后续规则，不追溯补扣资源、伤害或冷却；此默认语义需记录到设置说明。

## 3. 开发步骤与局部检查

### M4.1 集中管理设置和模式切换

建立少量训练配置、模式枚举和变更通知。切模式时停止旧移动与待执行请求，释放持续防御，按动作中断规则处理当前行为；受击等被动流程继续。

固定防御在角色可行动时请求 Guard，禁止状态不强开防御。静止模式只停止主动意图。

局部检查：固定防御→木桩后不再自动防御；受击中切模式也能正常恢复。

### M4.2 在规则层实现开关

无限生命必须接在有效伤害结算与死亡判断之间，明确原始伤害、结算伤害、实际扣血三种统计。无限资源同时影响检查与执行，不能仅 UI 显示满值。无冷却按对应冷却标签/句柄精确清理。

M4 若尚无正式技能，创建仅开发测试用能力，使用真实 GE 消耗和冷却，注明测试配置；禁止用改 UI 数字假装接入成功。M6 还要对移动炮、超级炮、形态切换和领域的实际规则复验。

局部检查：资源为零也能在无限资源模式执行合法测试能力；受击禁止时仍不能执行。

### M4.3 建立伤害和连击统计

从统一命中/受击事件收集有效伤害。连击延续依据目标是否恢复可行动及倒地保护规则；连击结束后再清计数/触发恢复。防御、空挥、无敌忽略与普通命中分别统计，不把全部接触计成伤害段。

明确溢出伤害与无限生命下的显示口径，避免用“剩余血量变化”替代输出统计。

局部检查：目标恢复后再命中记新连击；无限生命保留合理的伤害数字且不触发死亡。

### M4.4 接 UMG 与输入模式

面板显示双方生命/资源、当前模式、技能冷却、伤害、连击和输入记录。属性和战斗事件驱动更新；菜单打开释放持续战斗输入，关闭后恢复游戏输入与镜头。

订阅保存句柄，目标换绑/Widget 重建/销毁时成对解除。第一次显示主动读取当前状态，不依赖以后恰好收到变化事件。

局部检查：反复开关面板不叠加订阅，关闭面板不会留下鼠标占用或防御按住状态。

### M4.5 完成重置事务

暂停新请求与决策 → 取消能力与投技 → 清临时 GE、计时器、检测和表现 → 双方回初始变换并清速度 → 恢复属性/统计/缓存 → 重新分配目标 → 恢复指定模式。

默认保留训练开关和用户选择模式，战斗数值恢复初始配置。保留一次性授予的能力，不能每次重置重复授予或订阅；清理入口要允许重复调用。

局部检查：连续重置前后比较能力数、活动临时效果/对象数和 UI 回调次数；数值稳定。

## 7. 阶段实施记录：M4 / 2026-09-16

### 7.1 实现与所有权

- 接手版本为 M3 文档提交 `7b45b67`。继续使用现有角色、ASC、命中组件与集中重置，不新增平行战斗状态系统。
- `TrainingGameMode` 持有 `FTrainingSettings`、对手模式、双方输出统计、最近 8 条共享请求、生命恢复计时器与属性订阅句柄。静止模式只停主动意图；固定防御在真正恢复可行动后重新请求防御。AI 模式在 API 层拒绝、面板中禁用。
- `FighterCharacter::ApplyCombatDamage` 是普通命中、削血、投技共用伤害入口。无限生命在应用伤害 GE 前限制实际扣血，生命最低保留 1；受击、倒地与输出统计继续生效，不采用先死亡再回血。
- `FighterAbilitySystemComponent` 提供资源/冷却规则查询。M3 闪避已接无限资源；训练测试能力使用真实消耗 GE 和带 `Cooldown.Training.Probe` 标签的持续 GE。仅清这个明确注册的冷却，不清受击/防御等效果。
- 开发测试能力 `TrainingProbeAbility` 在非 Shipping 构建授予一次：合法激活消耗行动资源 1、咒力 10、领域能量 5，冷却 3 秒，无攻击伤害。资源为零时无限资源允许激活且不扣费；死亡、待处理受击、硬直、闪避恢复和菜单仍拒绝。它不是石流龙正式技能，M6 必须用正式炮击重测。
- `TrainingPanelWidget` 使用原生 UMG 控件树，未引入额外 UI 插件或业务 Tick。控制器的 `TrainingPanelClass` 可由薄蓝图替换；当前默认原生类。显示读取真实 ASC/训练统计，通过事件刷新；测试冷却活动期间使用 0.1 秒定时刷新，到期停止。
- 角色重生时 GameMode 成对解除/重建属性和战斗边界订阅；双方各 8 个属性订阅，总数 16。Widget 显示时唯一订阅，隐藏/重建/销毁时解除；首次显示主动读取当前值。
- 重置先同时停止双方请求，再取消能力、结束配对、清检测/状态/恢复计时与测试冷却，复位双方并恢复属性、近战形态、统计和目标，最后恢复指定模式。面板仍打开时继续禁止请求。能力不重复授予。

### 7.2 操作与默认语义

按 **F1** 打开/关闭训练面板，也可点击“返回战斗”；面板内 Escape 可关闭。打开时释放双方持续输入和旧攻击会话，暂停主动动作；被动受击/倒地过程照常结束。关闭后恢复游戏输入、鼠标捕获与镜头，旧松键不补招。默认木桩，四个训练开关均关闭，自动恢复延迟为 2 秒（面板可改 0.1—30 秒）。

- 自动恢复生命：目标实际恢复可行动后等待配置延迟，再次有效接触取消旧计划。死亡不自动复活。与无限生命独立。
- 无限生命：双方最低保留 1 点生命，仍受击、倒地、被投；关闭不补扣此前减免伤害。
- 无限资源：双方行动资源、咒力、领域能量的合法消耗检查放行并跳过扣费；不伪装成满条，不绕过状态限制。切换时先停主动会话，防止将来免费持炮跨设置延续。
- 无冷却：移除已有测试技能冷却，后续不再施加；不移除动作前后摇、闪避恢复或 E 的切形态间隔。关闭不补建过去跳过的冷却。
- 快速重置：保留开关、恢复延迟和对手模式，恢复定义初值并清统计。默认领域能量为 0，普通资源下测试技能需要测试脚本预置足够能量；开无限资源可直接从面板试验。
- 面板明确标记远程炮击、右键瞄准、蓄力和领域为 M6 未接入，AI 为 M5 未接入。

### 7.3 伤害与真连统计口径

统计按攻击方累计，区分双方：

| 字段 | 口径 |
| --- | --- |
| 原始伤害 | 有效接触时招式配置值；防御/闪避免疫也记录该接触原值，空挥为 0。 |
| 结算伤害 | 防御削血等规则处理后的伤害；无削血格挡/免疫为 0，包含超出剩余生命的溢出伤害，不受无限生命减免影响。 |
| 实际扣血 | 伤害 GE 应用前后生命差；受剩余生命和无限生命最低 1 点限制。 |
| 命中/防御/免疫/空挥 | 独立计数；一段接触按既有实例去重。开启过检测窗口且完全无接触才记空挥；未进入有效窗口的取消不记空挥。投技成功结算只记一次命中。 |
| 当前/上次连击 | 以被打目标真实恢复可行动为分界；倒地保护开始或死亡即结束。结束保留“上次”数值，再次命中建立新连击。防御、免疫不增加伤害段数。 |

当前 M3 白盒三段拳是可衔接的招式序列，0.5 秒受击硬直与实际接触时点会留下段间空隙，因此不能把“三段招式”直接显示成“三段真连”。测试另外临时将受击硬直延长到 0.8 秒，验证无恢复空隙时三次命中正确累计为 3 段 / 130 伤害，结束恢复原配置。M6 调整正式动画与时序后按相同真实边界复验。
