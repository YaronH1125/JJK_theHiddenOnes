# M5：AI 对战

版本：v0.1；建立日期：2026-09-15；实施与自测状态：待核验。

[开发过程导航](README.md) · 上一阶段：[M4](M4_训练系统.md) · 下一阶段：[M6](M6_角色与技能表现.md)

## 1. 目标与进入条件

让一个对手根据距离、资源和可观察状态进行攻防，经同一能力规则完成胜负与重开。M4 的模式切换、训练设置和重置已稳定；M3 的普攻、防御、闪避、条件投技可用。

采用 Behavior Tree + Blackboard。M5 先使用已有公共动作；M6 再加入石流龙重拳与炮击决策。本阶段不依赖正式技能、不建设感知系统或多人战术，也不长期保留另一套并行 AI 框架。

## 2. 预期交付与数据

| 对象/配置 | 需要承担的内容 |
| --- | --- |
| ArenaAIController | 接受 GameMode 指定目标，启动/停止决策与移动 |
| Blackboard | 目标、距离、可行动性、当前决策所需的观察值 |
| Behavior Tree | 接近、侧移、后退、攻击、防御、闪避与等待分支 |
| 动作 Task | 发共享请求，区分立即失败、已缓存、执行中、结束与中止 |
| 行为参数 | 反应延迟、决策间隔、距离阈值、保持时间和动作偏好 |
| 对局控制 | 胜负只结算一次，停止主动对抗并允许重开 |

生命/资源/冷却的真值仍在 ASC；Blackboard 可保存决策快照，但不能维护另一套可扣减数值。调试显示当前分支、意图、请求结果和等待原因。

## 3. 开发步骤与局部检查

### M5.1 接入目标、模式和寻路

GameMode 分配对手目标，进入 AI 模式才运行行为树，离开则停止行为与移动。白盒内核验 NavMesh 覆盖，记录导航代理尺寸与角色 Capsule 是否匹配；边界外不可到达。

失效目标进入等待/重新验证，禁止对空引用持续移动。木桩和固定防御沿用 M4 实现。

局部检查：模式切换可反复进行；进入 AI 后能识别正确目标并接近，退出立即停止主动意图。

### M5.2 先做距离行为

按距离选择接近、侧移或后退，目标点必须可行走且在边界内。采用不同进入/退出阈值或最小保持时间，避免距离阈值附近每帧切状态。

侧移方向可定时更换，后退在无空间时改为等待/侧移，不向墙内无限寻路。移动失败有明确返回与重试间隔。

局部检查：目标移动时 AI 可重新接近；在墙边不会持续抖动或越界。

### M5.3 接共享动作 Task

Task 提交动作请求，不能直接扣血或只播放攻击 Montage。区分“已缓存”和“已激活”：缓存请求需要过期/消费结果，不能立刻当攻击完成，也不能无限等待。

订阅与本次动作实例相关的结束事件，处理能力瞬间完成、激活失败、资源不足和冷却。任务结束/中止解除自己的订阅；取消动作须遵守该动作中断规则，不清除其他行为贡献的状态。

局部检查：AI 在受击禁止时请求会失败并等待，恢复后能继续；任务不会永久挂起。

### M5.4 增加攻防选择与反应参数

近距离请求普攻，通过配置概率/观察状态决定防御或闪避。投技沿用普攻接触防御目标后的条件分支，不给 AI 增加无条件远程抓取。

决策仅使用已可观察的攻击阶段、距离和资源等信息；不读取玩家尚未表现的输入来瞬间反制。调节反应延迟与决策间隔，保留固定随机种子或决策日志便于复现。

局部检查：改变难度参数能解释行为变化；不会每帧全知反击或无资源出招。

### M5.5 处理移动与战斗控制权

Root Motion、闪避、击退和投技开始时停止/暂停冲突的 AI Move 请求；动作结束按状态恢复决策。不能由寻路持续覆盖击退位置或将投技双方拉开。

切模式、死亡、重置都解除持续防御和旧动作缓存；已发生的命中不回滚。

局部检查：追击中受击会正确后退/硬直，恢复后重新决策；切木桩后没有旧追击。

### M5.6 完成胜负与重开

AI 对战中一方死亡后停止双方新主动行为，显示结果；结算本批已有效接触后再决定胜负，双方同批次死亡可用“平局”作为默认显示并记录规则。结果事件只发一次。

重开调用 M4 统一重置，清对局结束状态并恢复 AI。接通之前禁用的 AI 选项并更新面板说明。本阶段结束前建议产出一次 Development 独立运行包，尽早暴露地图、行为树与导航依赖问题。

局部检查：玩家赢、玩家输、平局/重开均无残留 Task 或重复结果。

## 5. 必须演示的闭环

进入训练 → 开启 AI → 拉开距离观察接近 → 近身攻防 → 一方死亡显示结果 → 重开 → 切木桩停止主动行为 → 再开启 AI。整个过程无需重新加载编辑器或手动修状态。
