# M5 体验修复与开发战斗 UI

日期：2026-09-17。按用户实机反馈补齐；正式角色、远程和领域仍属 M6。

## 第一阶段：F1 和 AI 移动动画

提交 `1caf464`。

- F1 被训练面板和引擎 BaseInput.ini 的 `viewmode wireframe` 同时绑定。项目 DefaultInput.ini 删除后者。旧验收直接调用 UMG 按钮，没有覆盖真实按键路径，导致漏检。
- AI 直接设置寻路速度时，加速度为 0；ABP_Unarmed 的 ShouldMove 为 false，角色滑行。开启导航的加速度驱动后，真实速度、加速度、ShouldMove 和脚部骨骼姿势均变化。
- 本次按键通过 Slate ProcessKeyDown/UpEvent 进入实际输入路由，验证连续 F1 开关和选择 AI 后仍为 Lit；不再以按钮回调代替快捷键验证。

## 第二阶段：Shift 与常驻 UI

提交 `c830e53`。

- 用户确认：移动按 Shift 冲刺闪避，继续按住持续跑；静止按 Shift 后撤，成功避开攻击保留闪避动作表现。
- 冲刺位移仍由单个 GAS RootMotionSource 负责。动画仅提供姿势，复制模板片段到 Training/Movement，对播放中的 Montage 实例禁用根运动并锁住根骨骼；没有修改模板源动画。
- 持续跑为普通移动速度的 1.5 倍，不重复扣行动资源。无敌结束可在恢复期继续移动，但攻击、切形态及再次闪避仍被恢复期阻止；疾跑本身没有无敌。
- 攻击、防御、受击、死亡、重置、菜单、失焦清疾跑意图；松 Shift 恢复普通速度。原普通闪避 1 点、取消闪避总计 2 点规则保留。
- 成功闪避仅由可闪避攻击的真实接触落在无敌窗口触发：HUD 显示 0.8 秒提示并点亮角色状态卡。没有提前读取对方输入、额外慢动作、伤害奖励或无敌延长。
- 新增 UCombatHudWidget：常驻双方生命、行动资源、咒力、领域能量，以及形态、状态、模式和训练开关。每 0.1 秒读取 ASC/GameMode，生命周期清定时器，不增加属性订阅，也不截获鼠标输入。F1 保留详细设置和统计。
- 闪避/后撤仍为现有冲刺和后退走路片段的明确占位，正式动作、特效与 UI 美术留 M6/M7。

## 验证与工具修复

新增图形检查覆盖真实键路由、AI 动画姿势、静止后撤、移动冲刺/持续跑、松键、资源不足、恢复期请求限制、菜单/失焦/受击清理、真实免疫接触、HUD 扣血/重置/目标销毁重生。

成功闪避专项临时把位移速度设为 0、腿击检测半径设为 300 cm，以保证真正发生接触；断言无伤害、免疫统计和反馈，随后恢复原参数。其他移动和战斗回归使用正常配置。

调试期间失败记录保留为 M5_Followup_*_failed_*。发现并修复了测试脚本的 Windows 报告文件读写竞争、异常后回调清理及可变结构配置快照问题。一次受污染的图形会话仅达到约 6.8—9.1 FPS，118 项 M3 中有 8 项失败；其结果不冒充目标帧率验收。最终结论以冷启动复测与独立包证据为准。

另一次冷启动 M3 图形回归只有后续攻击命中失败，定位到模板 Montage 带入额外根运动；能力层对该实例禁用根运动后，零闪避速度配置下实测额外位移为 0，正常移动冲刺速度为 900 cm/s。打包前引用检查还发现 AM_Dodge 指向模板原片段：嵌套结构修改没有标记包为 dirty，默认保存跳过了现有资产。生成脚本改为显式保存，再冷启动检查 Training/Movement 副本引用；模板资源没有修改。

最终 C++ 版本的完整规则回归通过：M3 118 项、M4 105 项、M5 68 项。证据为 M5_Followup_M3/M4/M5.json，均附源码、配置和资产 SHA256。M3 设置 30/60/120 FPS 时实测约 24.19/46.65/109.14 FPS，属于 nullrhi 规则回归，不声称达到目标帧率或代表渲染性能。这组完整规则回归在最后修正冲刺动画副本引用之前执行；修正后另做图形输入/位移专项与独立包验证。

最终资产冷启动检查通过（M5_Followup_AssetConfig.json），图形 PIE 专项 43 项全部通过（M5_Followup_UI.json）：后撤实际约 238.30 cm、移动冲刺 900 cm/s，零配置下无额外动画位移，持续跑 750 cm/s、松键恢复 500 cm/s。静止后撤位移按实际帧边界结束，当前不承诺每帧率下精确 225 cm。截图见 [常驻 UI](M5_修复_常驻战斗UI.png)、[AI 移动](M5_修复_AI移动与HUD.png)、[持续跑](M5_修复_Shift持续跑.png)、[成功闪避](M5_修复_闪避成功.png)。
