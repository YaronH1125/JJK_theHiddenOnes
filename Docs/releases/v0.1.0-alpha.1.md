# 《隐世之人》试玩版 v0.1.0-alpha.1

状态：**本地试玩候选 / 发行说明草案，尚未发布 GitHub Release**。更新日期：2026-10-03。

本候选已有完整 ZIP 与主菜单启动验证，但玩家随后反馈“启动后卡在地面”。问题尚未定位闭环，当前暂缓作为公开下载版本。下面的信息用于追溯已有候选；修复后发布新候选号。

## 可以体验什么

- 石流龙单角色，双方同角色；日式道场内单人训练与 AI 对战。
- 近战四段拳 / 三段腿、蓄力重拳 / 重踢、防御、冲刺 / 后撤与规则允许的动作取消。
- E 切换远程，使用移动蓄力炮、定点超级炮及按住右键瞄准。
- 项目原创领域“极宴流光”：自动曲线追踪炮，资源消耗、双领域压制及结束后的术式熔断。
- 战斗音效、受击、镜头、HUD 与可开关的局部顿帧；炮击命中后保持并渐退。
- 主菜单、暂停、操作说明、画面 / 音频 / 操作 / 训练设置，以及胜负、重开与退出流程。

角色和动作已有接入；部分通用 / 派生动作与领域表现仍在打磨。原创领域不表示原作已有该名称或完整设定。

## 如何运行

1. 完整解压到 `D:\Games`、`C:\Games` 等较短目录，进入 `JJK_Playtest_v0.1.0-alpha.1`。
2. 双击 `JJK_theHiddenOnes.exe` 可直接进入主菜单；`Play.cmd` 为开启顿帧并设置 60 FPS 上限的对照入口。
3. 保留 `Engine/`、`JJK_theHiddenOnes/` 和其他依赖；不要在 ZIP 内直接启动或只复制 exe。
4. 如提示缺少 VCRUNTIME / MSVCP，使用随包附带的 `Prerequisites/vc_redist.x64.exe` 安装运行库。

面向 Windows x64，开发与启动验证在本机完成；尚未给出其他机器通过或最低硬件配置结论。试玩不需要安装 UE 或取得源码原素材。完整按键见 [项目首页](../../README.md)。
