# 隐世之人 · 菜单视觉系统

深木道场作为真实空间底层，墨黑与深靛承担文字可读性，宋体标题、朱红笔触选中态与少量古金承接现有 HUD。

## 基础令牌

所有颜色从项目参考图采样后换算至 OKLch；交互与透明色在这些令牌上派生。

```css
--bg: oklch(0.15757 0.03952 253.214);     /* 角色图暗靛：RGB 2 13 29 */
--surface: oklch(0.16218 0.00847 296.891);/* 角色图深色衣服：RGB 14 13 17 */
--fg: oklch(0.93561 0.01072 100.829);    /* 毛领：RGB 235 234 226 */
--muted: oklch(0.76279 0.05484 72.437); /* HUD 古金：RGB 200 173 140 */
--border: oklch(0.40272 0.02555 78.8);   /* HUD 暗金：RGB 80 71 57 */
--accent: oklch(0.56082 0.13649 29.336); /* HUD 朱红：RGB 183 80 67 */
--display: 'STSong', 'SimSun', 'Songti SC', serif;
--body: 'Microsoft YaHei', 'PingFang SC', sans-serif;
--mono: 'Cascadia Mono', 'Consolas', monospace;
```

## 视觉规则

1. 道场使用项目实际截图清理后的底图；金像、雕梁、龙形雕刻、火盆和中央圆纹是空间识别点。
2. 菜单为非对称纵向层级。主菜单和暂停不使用网页卡片、侧边栏外壳或数据仪表盘。
3. 朱红只用于当前菜单笔触和关键确认；同屏最多两处。交互底色降低明度，保证米白文字对比。
4. 古金仅承担细线、序号和小面积识别；不铺满全屏边框。技能图标使用原创的细线、不完整圆环。
5. 角色使用现有石流龙插画。裁切仅用于装饰性立绘及 HUD 头像，其他界面不引入角色替身。
