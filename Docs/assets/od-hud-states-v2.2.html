设计说明

三条取舍的理由

A为什么双方能量条对称排布

照火影究极风暴4 的做法，把生命 → 咒力（紧贴）→ 离散资源格集中在两侧上角并左右镜像：咒力决定对手还能不能开炮，是玩家真正会读的对抗信息，所以对手侧同样给满。真正属于调试信息的（技能冷却、已支付咒力、领域会话、在途球数）留在调试层，不进主视野。

B为什么蓄力要显示强度上限

伤害与咒力是两个耦合变量：已支付咒力不足时，继续持炮不会提升伤害（仅剩 16 咒力时普通炮上限 60）。若不显式标出可支付区间，玩家会把“持炮更久”误当成“更强”。所以环上把超出支付能力的部分画成红橙虚线轮廓，读数直接锁在强度上限。

C为什么领域状态放顶部中央

领域是全局状态：同时影响双方，并决定接下来 6 秒的输出节奏。放在顶部中央，视线不离开对手即可读到剩余时间、三次自动炮时点与压制状态，同时完全不侵入中央擂台区。

03·b

条组材质（v2 升级手法）

层次不变，只换表面处理；每一层都是"外描边 → 深色内槽 → 亮部高光"三段式
部位处理手法为什么这样处理
生命条槽体1px 亮描边 + 内槽 inset 上暗下亮的双向阴影 + 顶部 1px 白色斜面把"线框"变成"管子"：上缘亮、下缘暗，眼睛会自动读成有厚度的实体
生命填充竖向三段渐变（#F6FDFF → #A8ECF8 → #5FC9E4）+ 0 0 16px 冷青外发光 + 内侧 1px 白高光冷白到浅青的三段比双色更有体积；外发光让条体在暗场景里"亮起来"而不是"贴上去"
前沿光刃2px 纯白竖条 + 双层投影（10px 白 / 22px 青）受击时最需要被看到的量就是"还剩多少"，前沿必须是最亮的一点
虚血残影深红竖向渐变（#8E2418 → #4A100C）+ 上缘 1px 淡红高光；0.6s 延迟 / 0.35s 回落加一道上缘高光后残影不再是一块死黑，读数时能分清"残影"与"空槽"
咒力条同语言、厚度 11px（生命 0.73 倍）+ 8% 处危险色刻度线带三角标记两层条必须"同族不同级"：材质一致保证同一套读数节奏，厚度与色相区分层级
头像框外 1px 亮线 → 2px 深色带 → 内层 1px；内缘 3px 身份色能量线（带 10px 光晕）+ 112° 斜向高光 + 底部 46% 暗角 + P1/P2 角标外亮内深的双描边是金属/能量框的通用做法；斜向高光避免方形头像显得平；底部暗角保证角标可读
顶部压暗带顶部 230px 竖向渐变 rgba(3,6,12,.72) → 透明条组直接压在擂台亮部会失去对比；一条压暗带让两侧条组"浮"出来，比给每个面板加底更干净
离散资源格切角小格 + 点亮态金色渐变 + 外发光；与条体同宽 5 等分保持"离散=可数"的语义，格数不变（5 格）
03·c

技能区规范（圆形聚类）

大招主位 + 普通技弧形簇
项规格理由
形状全部圆形，取消方角格圆形天然承载扇形冷却、外圈能量弧与外发光，不需要再挂一个进度条
体量层级大招 Ø120 : 普通技 Ø72 = 1.67 : 11.5–2 倍是「主位」可读的下限；再大就会把普通技挤出视野
聚类方式普通技圆心落在以大招为心、r=150 的弧上，步进 30°，角度中心固定 150°（左上）横排会丢主次；弧形 + 斜向错落让 4 个与 5 个保持同一视觉重心，切形态时不跳动
净距相邻圆心距 78.5（Ø72 → 净距 6.5）；与最近大招边缘净距 54弧长 = r × 弧度；30° 步进保证 32px 图标之间不挤
一格一键近战 3 格（左键 / Q / E）· 远程 4 格（左键 / Q / 右键 / E）轻招与重招共用同一个物理按键，显示成两格会让玩家以为有五个按钮；重招改为轻招格上的「派生」
轻 / 重共键表达角标写共享按键 → 主名写轻招 → 副行写「长按 → 重招」三行读法即规则本身：点按走轻招，按住过 0.18s 进重击；远程同理写成「按住蓄力 30→90」
长按记号圆右上角 17×17 角标，内含双下箭头（无弧线）扇形/圆弧已被冷却、能量、蓄力三种语言占用，用弧线表示「可长按」会产生假信号；双下箭头 + 副行文字是唯一语义
状态互斥蓄力进行中（正在使用）自动隐藏长按角标该状态本身就在表达「按住」，两者同现会让画面变花
名称 / 角标名称贴在圆外侧（左侧）、右对齐两行（主名 10.5 / 副行 9）；按键角标压在圆下缘弧的内侧朝向大招，标签放外侧才不会互相压；副行只在有派生时出现
冷却表现圆形扇形由 -90° 扫过（conic-gradient），中心叠倒数圆形按钮的天然表达，替代底部进度条
能量表现大招能量环与按钮同心贴合：viewBox 120 = 按钮 120px，r=57 → 环外缘半径 58.5，落在按钮 60px 半径内 1.5px；能量 < 0.5% 时 fgc 不透明度归零原实现 inset:-8px 使环直径 130.6 > 按钮 120，能量为 0 时只剩一圈悬在按钮外的淡蓝，被读成孤立圆圈；改为贴边后它是按钮自己的能量边。另：零长度 dash 在 stroke-linecap:round 下仍会渲染出一个圆点，rotate(-90deg) 后正好落在环正上方 —— 低能量必须连同不透明度一起归零，跨阈值时 dasharray 与 opacity 同步 0.25s 淡入
可用态外发光：大招呼吸 1.5s，普通技静态光晕不改图标本体，避免五态切换时识别断裂
占用与净空聚类整体 x 1580–1846 / y 745–1020；与下中蓄力环（x 820–1100）保留 480px 净空不与底部键位行、蓄力环重叠
前提说明：本轮没有可核验的二游（原神 / 鸣潮）实机界面参考图——能抓到的素材都是宣传立绘或非界面图。因此圆形聚类的形状、直径比、弧线半径与步进角均为按通用二游 HUD 常识 + 本项目分辨率自定，不是实测值；条组的层次与厚度比例则来自火影截图（ref-naruto-storm4-hud.jpg / -zoom.png）的逐像素实测，两部分的依据强度不同，正式美术期请按这条区分对待。
