# JJK: The Hidden Ones / 隐世之人 · 菜单 UI 规格

## 交付与打开方式

- 入口：[menu-ui-v1.0.html](assets/menu-ui-v1.0.html)。默认主菜单，直接用 Microsoft Edge 打开或在项目预览中打开。
- 单文件内联 CSS、JavaScript、JPEG 图像及 SVG 图标；UTF-8 无 BOM，无网络字体、资源请求或第三方脚本。
- 原始画布 1920 × 1080；1280 × 720 完整等比例缩至 2/3。不滚动、不重排菜单，不出现水平滚动条。
- 本文件提供视觉、UMG 布局、交互和实现边界；[brand-spec.md](assets/menu-ui-v1/brand-spec.md) 保存参考图采样形成的视觉令牌。
- `assets/menu-ui-v1/preview/` 保存主要界面截图和核验结果；`assets/menu-ui-v1/tools/` 保存制作阶段 Edge 核验脚本（运行前需调整其中的项目路径）。
- 审阅模式使用 `assets/menu-ui-v1.0.html?review=1`。右上角界面选择器仅在该模式出现；普通入口不含审阅工具。

## 目标与内容边界

设计对象是 Unreal 单机第三人称动作对战菜单，网页承担设计预览。当前唯一角色为石流龙，双方均使用石流龙；场地为当前 `L_DojoArena / Mishima_DOJO`。

主菜单提供开始游戏、训练模式、设置、操作说明与退出。开始页只提供 AI 对战和自由训练。没有剧情、联网、抽卡、商店、新地图或多人选角。

「极宴流光」是项目原创领域工作名；本稿只显示“领域”按键，未将原创内容表述为官方设定。

## 美术与素材

以实际日式木质道场为主体：中央金像与放射背板、两侧雕像/龙形雕刻、雕花梁柱、灯笼、火盆、中央圆纹、木板地面。深墨遮罩保证菜单文字稳定可读，同时保留火光和空间纵深。

主菜单与模式页使用左侧纵向层级、右侧石流龙立绘。菜单的唯一强装饰是朱红笔触；选中时附细小序号与箭头。设置采用薄分隔线、左右步进器、轻薄开关和滑杆。技能图标为原创线条及不完整圆环，没有复制其他游戏的具体图形或菜单构图。

## 颜色与字体

```css
--bg: oklch(0.15757 0.03952 253.214);
--surface: oklch(0.16218 0.00847 296.891);
--fg: oklch(0.93561 0.01072 100.829);
--muted: oklch(0.76279 0.05484 72.437);
--border: oklch(0.40272 0.02555 78.8);
--accent: oklch(0.56082 0.13649 29.336);
```

| 用途 | 字体 / 大小（1920 原稿） |
|---|---|
| 游戏大标题 | STSong / SimSun / Songti SC / serif，92 px，常规字重 |
| 页面标题 | 同显示字体，64 px；退出状态 60 px |
| 主菜单 / 暂停项 | 同显示字体，32 px；设置类别 27 px |
| 设置页内容标题 | 同显示字体，40 px |
| 正文、设置标签 | Microsoft YaHei / PingFang SC / sans-serif，22–24 px |
| 操作页动作名 | 正文字体，22 px；按键芯片 18–20 px |
| 次级说明 / 键盘提示 | 18–20 px；攻击补充说明 16 px |
| 英文副标 / 序号 / 数值 | Cascadia Mono / Consolas / monospace，16–22 px |

朱红实际按钮填充在 `--accent` 上降低 L 0.085；hover 降低 L 0.15，前景始终为 `--fg`。实测文字对比度：默认主色按钮 **5.93:1**，hover **7.81:1**，面板米白文字 **16.05:1**。禁用态单独降低明度与透明度，其他状态不把文本改为更浅的灰色。

古金 `--muted` 用于注释、序号与细线。生命与咒力使用独立的语义填充色：`oklch(0.64 .085 145)` 与 `oklch(0.72 .07 232)`，仅在 HUD 数据条出现。

全部字体使用本机回退；跨机器的汉字字面与宽度可能有细小差异。UMG 实装应选定并依法打包一个中文宋体及一个正文黑体，以固定字体度量。

## 界面与状态迁移

页面内存状态：`main`、`start`、`battle`、`pause`、`settings`、`controls`、`exit`。确认层独立于基础页面，类型为 `restart`、`returnMain`、`quit`、`unsaved`。

| 起点 | 触发 | 终点 / 行为 |
|---|---|---|
| 启动 / 页面重载 | 打开入口 | `main`；已应用的偏好恢复，页面位置不恢复 |
| 主菜单 | 开始游戏 | `start`，预选 AI 对战 |
| 主菜单 | 训练模式 | `start`，预选自由训练 |
| 模式选择 | 两个选项 | 修改模式；选中菱形与“开始对战/开始训练”文案更新 |
| 模式选择 | 开始对战 / 开始训练 | `battle`，展示对应模式的 HUD |
| 模式选择 | 返回 / Esc | `main`，恢复对应入口焦点 |
| 对战 | Esc 或暂停按钮 | `pause`；当前场景压暗并模糊，首选继续游戏 |
| 暂停 | 继续游戏 / Esc | `battle` |
| 暂停 | 重新开始 | `restart` 确认；取消停留暂停，确认返回对战并反馈“本局已重新开始” |
| 暂停 | 返回主菜单 | `returnMain` 确认；确认结束当前界面会话，进入 `main` |
| 主菜单 | 退出游戏 / Esc | `quit` 确认；确认进入 `exit` |
| 退出状态 | 返回标题界面 | `main` |
| 主菜单 | 设置 | `settings(graphics)`，来源主菜单，使用暖光道场底图 |
| 暂停 | 游戏设置 | `settings(graphics)`，来源暂停，保留当前战斗底图 |
| 暂停 | 训练设置 | `settings(training)`，来源暂停 |
| 对战 | F1 / 训练设置按钮 | 先按暂停语义进入训练设置，返回来源为暂停菜单 |
| 设置 | 切换四类页面 | 保留同一份草稿；切换页不保存、不丢弃 |
| 设置 | 应用更改 | 更新已应用设置、持久化；保留当前设置页，并显示反馈 |
| 设置 | 恢复默认 | 所有类别恢复默认草稿；需应用后保存，未自动提交 |
| 设置，无改动 | 返回 / 取消 / Esc | 返回进入它的菜单，恢复入口控件焦点 |
| 设置，有改动 | 返回 / 取消 / Esc | `unsaved`：继续调整、放弃更改、应用并返回 |
| 未应用弹窗 | 继续调整 / Esc | 保留草稿与类别，回到原控件 |
| 未应用弹窗 | 放弃更改 | 回到来源菜单；取消预览亮度与未提交值 |
| 未应用弹窗 | 应用并返回 | 保存后回到来源菜单 |
| 主菜单 / 暂停 / 设置 | 操作说明 | `controls`；保留明确来源及返回焦点 |
| 操作说明 | 返回 / Esc | 回到实际来源；来源设置时保留类别与未应用草稿 |

退出状态在浏览器内展示原型结束，不尝试关闭用户的浏览器。

### 当前对手与设置草稿

开始 AI 对战时当前对手为 AI；自由训练使用已应用的训练对手偏好。暂停来源的设置以当前对手作为编辑基线，避免“刚打开就出现未应用更改”。应用训练对手时同步当前会话的 HUD；若从 AI 对战改为静止木桩或固定防御，该会话改标自由训练。

草稿与进入设置时的基线对比产生 dirty 状态；应用后刷新基线。取消或放弃不修改已应用偏好。主菜单来源的设置直接以已应用偏好为基线。

## 焦点与交互状态

- 主菜单与暂停：↑↓循环移动，Enter/Space 激活，鼠标 hover 改变选中笔触。初始选中开始游戏；重新打开暂停时保留本会话的菜单选项。
- 模式页：↑↓在两个模式间移动焦点，Enter/Space 选中；Tab 可到唯一开始按钮，Esc 返回。
- 设置类别：方向键循环切换类别并将焦点保留在对应标签；所有类别共用草稿。
- 设置行：↑↓移至相邻可用设置行；←→调整步进值或开关；滑杆使用原生方向键步长。步进到边界会禁用一侧按钮，焦点自动转到同一行另一侧。
- Tab/Shift+Tab 在当前界面所有可用控件间循环。禁用控件不进入顺序。
- 键盘输入启用 2 px 米白 focus-visible 外圈；鼠标操作取消键盘圈，保持 selected/hover 提示。
- 确认弹窗打开时基础页 `inert`；Tab 和方向键只在弹窗内循环。默认焦点落“取消/继续调整”，Enter 不会直接执行破坏性操作。
- 弹窗 Esc 取消并恢复触发控件。点击弹窗外不关闭；防止误触。
- 按钮 hover 加深朱红或增强底色/边框，文字保持米白。selected、hover、focus、disabled 分别可辨识。
- 设置“应用更改”在无改动时禁用；自动恢复关闭时恢复延迟禁用。
- 页面出现动画 180 ms，反馈 2.4 s；支持 `prefers-reduced-motion`，关闭页面/控件动画。

| 设置动作、底部提示 | 底部横向伸展 | 动作底距 91；提示底距 48 |

### UMG 状态管理与接线建议

建立 `EMenuScreen`、`EMenuOrigin`、`EConfirmAction`，控制器保存当前界面、来源、返回焦点控件、已应用设置、进入基线、编辑草稿、当前对手模式。不要根据“上一帧显示了哪个 Widget”推断来源。

- Main/Start/Settings/Controls/Confirm 使用可见鼠标与菜单输入模式；Battle 交还游戏输入；Pause 停止当前对战输入。
- 同人单机 Demo 可由 PlayerController 执行暂停与输入模式切换；确认/反馈需使用不受暂停影响的界面时间源。
- NativeOnKeyDown 统一处理 Esc 和方向键，返回 Handled，避免暂停键继续传入战斗技能绑定。
- WidgetSwitcher 页面显示后显式 SetUserFocus；方向导航使用显式邻接关系，保留来源控件引用或稳定 ID。
- 确认层只接收一种待确认动作；取消释放模态并还原焦点，确认后只执行一次回调。
- 画面建议接到 `UGameUserSettings`：显示模式、分辨率、品质、VSync、帧率上限；实际分辨率变更是否需要回退倒计时，由后续引擎接入决定。
- 音量接到项目 SoundClass/SoundMix 或音频设置层；总音量与分类值分别保存。
- 操作设置接到视角输入、垂直反转、镜头震动开关；本稿不提供改键功能。
- 训练项接到现有训练面板/训练配置入口，沿用项目既有语义；重开统一调用本局重置，不重新创造另一套重置逻辑。
- 长期偏好与实时训练会话可在引擎端分层保存；网页的 localStorage 仅用于设计演示，不能视为游戏存档格式。

以上是实装建议，未读取、编译或修改游戏工程，也未确认具体 C++ 类名、蓝图引用或现有 API 可用性。
